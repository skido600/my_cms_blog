# MyBlog

A full-stack blogging platform that handles writing, publishing, and audience engagement from one codebase. It gives authors a clean admin experience and gives readers fast, cached post browsing with automatic email updates when new content drops.

## Overview

This project helps developers and content teams run a complete personal or publication blog without stitching together a dozen separate tools. It handles content management, image hosting, reader subscriptions, and automated email notifications, so authors can focus on writing while the platform keeps readers in the loop.

## Features

- **Content management** — Create, edit, feature, and delete posts with rich descriptions and header images.
- **Smart slugs** — Auto-generates unique URL slugs from post titles.
- **Secure admin auth** — JWT access and refresh tokens stored in signed HTTP-only cookies.
- **Rate limiting** — Redis-backed sliding-window rate limits protect public and admin routes.
- **Caching** — Hot posts, categories, and featured content are cached in Redis for fast reads.
- **Subscriber system** — Double opt-in subscriptions with verification tokens and one-click unsubscribe.
- **Automated emails** — New post alerts and monthly reminder newsletters sent in small batches.
- **Image uploads** — Header images go straight to Cloudinary with unsigned upload presets.
- **Workflow automation** — Recurring monthly reminders and new-post notifications run as durable workflows.

## Usage

Run the whole monorepo in development with Turbo:

```bash
pnpm dev
```

The API starts on port `3000` by default:

```bash
http://localhost:3000/api/v1
```

Fill in your environment variables in `apps/api/.env`:

```bash
DATABASE_URL=
ADMIN_EMAIL=
ADMIN_PASSWORD=
JWT_ACCESS_SECRET=
JWT_REFRESH_SECRET=
CLOUDINARY_UPLOAD_PRESET=
CLOUDINARY_CLOUD_NAME=
COOKIE_SECRET=
VERCEL_ENV=
API_URL=
WEB_URL=
ADMIN_SECRET=
UPSTASH_REDIS_REST_TOKEN=
UPSTASH_REDIS_REST_URL=
```

Apply database migrations with Drizzle Kit:

```bash
pnpm --filter api exec drizzle-kit migrate
```

Build everything for production:

```bash
pnpm build
```
